
# Сквозной продуктовый и финансовый аудит сети фитнес-клубов SkySport на Python

##  Бизнес-контекст и проблематика проекта
Для оптимизации продуктовой линейки, запуска новых безлимитных абонементов и точечной настройки маркетинговых кампаний федеральной сети SkySport требовалось масштабное исследование клиентской базы. 

Основная сложность заключалась в высоком уровне "шума" в сырых данных: наличии инфраструктурных аномалий (ошибок ввода, b2b-закупок) и эффекте правого цензурирования (смещения метрик из-за новых пользователей, чей жизненный цикл еще не завершен).

**Цель проекта:** Очистить исторические данные, рассчитать честные метрики юнит-экономики (LT, LTR) на основе когортного анализа, оценить реальную маржинальность маркетинговых акций и провести глубокое профилирование аудитории.

## 🛠 Технический стек и методы
* **Стек:** Python (Pandas, NumPy, Matplotlib, Seaborn), Jupyter Notebook.
* **Методология:** Статистический анализ распределений, метод межквартильного размаха (IQR) для фильтрации аномалий, импутация пропусков на основе матрицы тарифов, когортный анализ (Cohort Analysis).

##  Структура исследования и ключевые результаты

### Блок 1. Предобработка данных и базовая фильтрация аномалий
* Реализована автоматическая фильтрация аномалий по методу IQR. 
* Исходный расчет выдавал средний возраст клиентов **35 лет** (из-за выбросов в виде правосторонних ошибок ввода — клиентов 88 лет). 
* Алгоритм IQR определил границы нормы (до 69.5 лет), скорректировав метрику ядра целевой аудитории до **30 лет**. Это фундаментально изменило Buyer Persona для отдела маркетинга.
* Успешно проведена продвинутая импутация 715 пропусков в суммах платежей на основе матрицы тарифов (`group` = 800 руб., `indiv` = 1800/1600 руб.).

### Блок 2. Расчет базовых метрик юнит-экономики (LT / LTR) и аудит акций
* Для устранения эффекта цензурирования данных были изолированы зрелые когорты пользователей (пришедшие в январе-апреле 2023 года) с завершенным циклом наблюдений.
* **Результат:** Истинный показатель **Lifetime (LT)** составил **6.25 месяцев** (медиана — 7 месяцев). Средний очищенный **LTR** равен **43 927.63 руб.** (медиана — 36 000 руб.). Прямой расчет по сырым данным недооценивал ценность клиента более чем на 11 000 рублей.
* **"Ловушка выручки" в маркетинге:** Майская акция (персоналки по 1600 руб.) принесла **+390 800 руб. выручки**. Однако расчет чистой маржи показал **отрицательный прирост прибыли (-400 руб.)**. Добавочный кэш был полностью поглощен операционными костами — фиксированными выплатами тренерам (800 руб. за сессию).

### Блок 3. Сегментация, профилирование и региональный макроанализ
* **Региональные кластеры:** Москва — абсолютный премиум-рынок с долей индивидуальных тренировок **65.4%** и максимальным ARPU. Санкт-Петербург показывает высокую эффективность за счет плотности групповых программ (чек практически равен московскому при доле персоналок всего в **33.3%**).
* **Поведенческий анализ:** Выделено премиальное ядро клиентов (`share_indiv > 0.7`) и составлен их гендерно-географический портрет для кастомизации локальной рекламы.
* **Жизненный цикл базы:** Реализован алгоритм разделения лога активности на три составляющие: приток новых пользователей (New), финальный отток (Gone) и MAU по месяцам, позволяющий CRM-системе точечно запускать триггерные рассылки для удержания клиентов.
